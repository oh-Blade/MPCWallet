MPC 2-of-3 门限签名详细过程
假设 P1, P2 参与签名，P3 缺席。使用 ECDSA。

---
前置状态（DKG 完成后各方持有）
P1 持有：d₁（私钥份额），Q（公钥），所有承诺 Aᵢⱼ
P2 持有：d₂（私钥份额），Q（公钥），所有承诺 Aᵢⱼ
P3 持有：d₃（私钥份额），Q（公钥），所有承诺 Aᵢⱼ

d₁ = f₁(1) + f₂(1) + f₃(1)
d₂ = f₁(2) + f₂(2) + f₃(2)
d₃ = f₁(3) + f₂(3) + f₃(3)
d₁, d₂, d₃ 是多项式上的点，满足 Shamir 关系，任意两方用拉格朗日插值可还原 d，但协议保证插值过程发生在加密域，d 明文永不出现。

---
第一步：确定参与方和拉格朗日系数
拉格朗日插值的目标
已知两个点 (1, f(1)) 和 (2, f(2))，还原 f(0)。
拉格朗日公式：
f(0) = Σ λᵢ · f(i)
其中拉格朗日系数：
λᵢ = Π (0 - xⱼ) / (xᵢ - xⱼ)    j ≠ i
逐个计算
P1, P2 参与，编号为 1, 2，计算拉格朗日系数：
计算 λ₁（i=1，j=2）：
λ₁ = (0 - x₂) / (x₁ - x₂)
   = (0 - 2) / (1 - 2)
   = (-2) / (-1)
   = 2
计算 λ₂（i=2，j=1）：
λ₂ = (0 - x₁) / (x₂ - x₁)
   = (0 - 1) / (2 - 1)
   = (-1) / (1)
   = -1

验证：
λ₁·d₁ + λ₂·d₂ = 2·f(1) - 1·f(2)
               = 2(a₀+a₁) - (a₀+2a₁)
               = a₀
               = d   ✓
这两个系数是公开的，双方都知道，签名开始前就能算出。

---
第二步：分布式生成 nonce（最复杂的部分）
需要生成随机 nonce k 和对应曲线点 R = k·G，同样用 DKG 的方式，但是一次性的。
P1, P2 各自生成 nonce 份额多项式：
P1 生成：g₁(x) = b₁₀ + b₁₁·x
P2 生成：g₂(x) = b₂₀ + b₂₁·x
广播 nonce 承诺：
P1 广播：{ B₁₀ = b₁₀·G,  B₁₁ = b₁₁·G }
P2 广播：{ B₂₀ = b₂₀·G,  B₂₁ = b₂₁·G }
点对点交换 nonce 份额：
P1 → P2 发送：g₁(2) = b₁₀ + 2b₁₁
P2 → P1 发送：g₂(1) = b₂₀ + b₂₁
各方汇总自己的 nonce 份额：
k₁ = g₁(1) + g₂(1) = (b₁₀+b₁₁) + (b₂₀+b₂₁)
k₂ = g₁(2) + g₂(2) = (b₁₀+2b₁₁) + (b₂₀+2b₂₁)
计算 R：
R₁ = k₁·G
R₂ = k₂·G

R = λ₁·R₁ + λ₂·R₂
  = 2·R₁ - R₂
  = 2·(k₁·G) - (k₂·G)
  = (2k₁ - k₂)·G
  = k·G   ✓

r = R.x

---
第三步：计算签名份额 s
普通 ECDSA 签名：
s = k⁻¹·(hash(m) + r·d)
MPC 中需要在不暴露 k 和 d 的情况下计算出 s。

---
问题：k⁻¹ 怎么处理？
需要引入辅助随机数来盲化 k。
各方生成盲化份额：
P1 生成随机数 ρ₁
P2 生成随机数 ρ₂

P1,P2 通过乘法 MPC 协议计算：
  ρ  = ρ₁ + ρ₂           （加法组合）
  ρk = ρ·k               （乘法，通过 MPC 完成，见下方）
乘法 MPC（计算 ρ·k）用 Paillier 同态加密：
P1 用 Paillier 公钥加密：Enc(ρ₁·k₁·λ₁)
P2 在密文上操作（同态乘法和加法）：
   密文 × (ρ₂·k₂·λ₂) → 在明文域等价于加上 ρ₂·k₂·λ₂
最终解密得到：ρk = ρ₁·k₁·λ₁ + ρ₂·k₂·λ₂ = ρ·k
计算 (ρk)⁻¹ 是公开的：
ρk 的值双方都知道（解密后广播）
(ρk)⁻¹ = 1/(ρ·k)  直接计算

---
各方计算签名份额
P1 计算：
s₁ = (ρk)⁻¹ · (ρ₁·λ₁·hash(m) + ρ₁·r·λ₁·d₁)
   = (ρk)⁻¹ · ρ₁·λ₁ · (hash(m) + r·d₁)
P2 计算：
s₂ = (ρk)⁻¹ · (ρ₂·λ₂·hash(m) + ρ₂·r·λ₂·d₂)
   = (ρk)⁻¹ · ρ₂·λ₂ · (hash(m) + r·d₂)
合并 s₁ + s₂：
s = s₁ + s₂
  = (ρk)⁻¹ · [ρ₁·λ₁·(hash(m)+r·d₁) + ρ₂·λ₂·(hash(m)+r·d₂)]
  = (ρk)⁻¹ · [(ρ₁λ₁+ρ₂λ₂)·hash(m) + r·(ρ₁λ₁d₁+ρ₂λ₂d₂)]
  = (ρk)⁻¹ · [ρ·hash(m) + r·ρ·d]     ← ρ=ρ₁λ₁+ρ₂λ₂，d=λ₁d₁+λ₂d₂
  = k⁻¹ · (hash(m) + r·d)             ← ρ 约掉
  = s   ✓

---
第四步：输出最终签名
签名 = (r, s)
与普通 ECDSA 签名格式完全相同，任何标准验签方无法区分。

---
完整数据流
        P1                              P2

持有    d₁, λ₁=2                       d₂, λ₂=-1

Step1   确定 λ₁, λ₂  ←————————————→   确定 λ₁, λ₂

Step2   广播 B₁₀,B₁₁  ————————————→   收到承诺
        收到承诺       ←———————————— 广播 B₂₀,B₂₁
        收到 g₂(1)    ←———————————— 发送 g₂(1)（加密）
        发送 g₁(2)    ————————————→  收到 g₁(2)（加密）
        本地算 k₁,R₁                  本地算 k₂,R₂
        R = 2R₁-R₂  ←————————————→  R = 2R₁-R₂
        r = R.x                       r = R.x

Step3   Enc(ρ₁k₁λ₁)  ————————————→  同态运算后解密
                      ←————————————  广播 ρk
        本地算 s₁                     本地算 s₂
        s = s₁ + s₂  ←————————————→  s = s₁ + s₂

输出    (r, s)                        (r, s)

---
一句话总结
签名过程是 DKG 的镜像：nonce k 用同样的方式分布式生成，拉格朗日系数 λ 把门限关系编码进每一步运算，Paillier 同态加密解决了 k⁻¹ 和 d 相乘的问题，盲化因子 ρ 防止中间值泄露任何份额信息，最终 s₁+s₂ 合并时 ρ 自然消去，得到标准 ECDSA 签名。
