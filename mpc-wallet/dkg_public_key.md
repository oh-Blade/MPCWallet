MPC  DKG  公钥生成（2-of-3）
DKG 的核心思想：每一方都贡献一部分随机性，没有任何一方能控制最终私钥。

---
每一方生成自己的多项式
2-of-3 门限，需要 1次多项式（degree = threshold - 1 = 1）：
P1 随机生成：f₁(x) = a₁₀ + a₁₁·x
P2 随机生成：f₂(x) = a₂₀ + a₂₁·x
P3 随机生成：f₃(x) = a₃₀ + a₃₁·x
其中 a₁₀, a₂₀, a₃₀ 是各方的私密随机数，是各自对最终私钥的贡献。

---
第一轮广播：承诺（Commitment）
每方把自己多项式的系数对应的曲线点公开广播，这叫 Feldman VSS 承诺：
P1 广播：{ A₁₀ = a₁₀·G,  A₁₁ = a₁₁·G }
P2 广播：{ A₂₀ = a₂₀·G,  A₂₁ = a₂₁·G }
P3 广播：{ A₃₀ = a₃₀·G,  A₃₁ = a₃₁·G }
广播的是曲线点，不是系数本身，离散对数保证安全。
此时每方已经可以计算出最终公钥：
Q = A₁₀ + A₂₀ + A₃₀
  = a₁₀·G + a₂₀·G + a₃₀·G
  = (a₁₀ + a₂₀ + a₃₀)·G
  = d·G   

---
第二轮私密发送：份额分发
每方把自己多项式在其他人编号处的取值，点对点加密发送：
P1 → P2 发送：f₁(2) = a₁₀ + a₁₁·2   （加密传输）
P1 → P3 发送：f₁(3) = a₁₀ + a₁₁·3   （加密传输）

P2 → P1 发送：f₂(1) = a₂₀ + a₂₁·1   （加密传输）
P2 → P3 发送：f₂(3) = a₂₀ + a₂₁·3   （加密传输）

P3 → P1 发送：f₃(1) = a₃₀ + a₃₁·1   （加密传输）
P3 → P2 发送：f₃(2) = a₃₀ + a₃₁·2   （加密传输）

---
每方汇总自己的最终私钥份额
d₁ = f₁(1) + f₂(1) + f₃(1)
   = (a₁₀ + a₁₁) + (a₂₀ + a₂₁) + (a₃₀ + a₃₁)

d₂ = f₁(2) + f₂(2) + f₃(2)
   = (a₁₀ + 2a₁₁) + (a₂₀ + 2a₂₁) + (a₃₀ + 2a₃₁)

d₃ = f₁(3) + f₂(3) + f₃(3)
   = (a₁₀ + 3a₁₁) + (a₂₀ + 3a₂₁) + (a₃₀ + 3a₃₁)
每方只知道自己的 dᵢ，不知道其他人的份额，也不知道 d。

---
验证份额的正确性
P1 收到 f₂(1) 和 f₃(1) 后，如何确认对方没有发假数据？
用第一轮广播的承诺验证：
验证 f₂(1) 是否正确：           （f₂(1)来源于私密发送）
  f₂(1)·G  ?= A₂₀ + 1·A₂₁
            = a₂₀·G + a₂₁·G
            = (a₂₀ + a₂₁)·G   （来源于广播）
在曲线点上验证，不需要知道 a₂₀, a₂₁ 的明文。

---
完整数据流汇总
        P1              P2              P3
        
第一轮  广播            广播            广播
        A₁₀,A₁₁  →→→  A₂₀,A₂₁  →→→  A₃₀,A₃₁
        （所有人都收到所有承诺）

第二轮  f₂(1)←←←P2    f₁(2)←←←P1    f₁(3)←←←P1
        f₃(1)←←←P3    f₃(2)←←←P3    f₂(3)←←←P2
        （点对点加密，只有目标方能解密）

结果
公钥    Q = A₁₀+A₂₀+A₃₀   （三方独立计算，结果相同）
私钥份额  d₁               d₂               d₃

---
一句话总结
三方各自贡献一个随机多项式，公开广播系数的曲线点让所有人能算出同一个公钥 Q，私密发送多项式取值让每方得到自己的私钥份额 dᵢ。整个过程没有任何人知道完整私钥 d，公钥 Q 是三方随机性叠加的结果，没有任何一方能操控它。
