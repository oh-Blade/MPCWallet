核心模块规划
# TSS 密钥管理层（Go, tss-lib）
GG20 协议的分布式密钥生成（DKG）
无可信中心的密钥分片，支持 secp256k1（ETH）
密钥刷新（Key Refresh / Resharing）防止长期密钥泄露

# 网络通信层
各参与方之间的 P2P 通信
可靠广播机制（tss-lib 要求）
会话管理和超时处理

# 以太坊集成
go-ethereum 构建和广播 ETH 交易
EIP-1559 gas 管理
ERC-20 Token 支持
Nonce 管理（防止重放攻击）
ETH + 主流 ERC-20（USDT/USDC/WETH等）

# 客户端
钱包创建和 DKG 流程可视化
交易发起、签名流程
多参与方状态同步
地址簿 & 历史记录

# MPC阈值可配置
用户自己选择是一共几方参与，多少方签名
